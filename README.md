# R-loop transcriptional programs in breast cancer

This repository contains the R code used for the analyses in the accompanying manuscript.

## Repository structure

- `01_data_preprocessing/` - preprocessing of TCGA, METABRIC, GEO bulk datasets, and single-cell datasets
- `02_bulk_analysis/` - R-loop scoring, WGCNA, consensus clustering, RL-Sig65 derivation, and NAC validation
- `03_scRNA_discovery/` - malignant epithelial-cell analysis, CytoTRACE2, and Slingshot in GSE306201
- `04_hdWGCNA/` - hdWGCNA and candidate-gene selection
- `05_scRNA_validation/` - independent single-cell validation in GSE245601
- `06_DRIP_validation/` - E2-induced DRIP, RNase H1, and pan-proliferation specificity analyses
- `07_virtual_knockout/` - scTenifoldKnk analyses in C5 and C4 malignant epithelial cells
- `08_RNAPII_validation/` - H2A.Z-RNAPII analysis
- `gene_sets/` - study-defined gene sets used in downstream analyses

## Data

Raw public datasets are not redistributed in this repository. Download the datasets from their original repositories and place them under `data/raw/` as described in `data/README.md`.

Large intermediate Seurat objects are also not included. They are generated by the preprocessing scripts.

## Usage

Run the scripts from the repository root. Scripts within each directory are numbered in the recommended execution order.

The code assumes R and the package versions reported in the manuscript. Package information is summarized in `environment/package_versions.tsv`.

## Reproducibility

Random seeds used in the final analyses are retained in the corresponding scripts. Output files are written to `results/`, which is excluded from version control.
